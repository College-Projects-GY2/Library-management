# מערכת ניהול ספרייה (Library Management System)

מערכת קונסול (Console) מלאה לניהול ספרייה, כתובה ב-Java. המערכת מוכנה לשימוש ונבנתה לצורך תרגול, למידה ושיתוף ב-GitHub.

## תכונות מרכזיות

* **מערכת הרשמה והתחברות:** תמיכה במשתמשים רגילים, משתמשי פרימיום ומנהל מערכת (Admin).
* **תפריטים לפי הרשאות:**
  * **מנהל:** הוספה והסרה של ספרים, צפייה בכל מלאי הספרים וחיפוש.
  * **משתמש:** השאלה והחזרה של ספרים (מוגבל לפי סוג המנוי - רגיל/פרימיום), צפייה ברשימת הספרים המושאלים וחיפוש ספרים.
* **בדיקות תקינות קלט:** אימות אלגוריתמי לתעודת זהות (ספרת ביקורת) ואכיפת סיסמאות חזקות.
